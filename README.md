### **📌 JavaScript Projects**  

This repository contains multiple JavaScript projects that help in learning and practicing fundamental JS concepts. Each project is interactive and fun to use! 🚀  

## **📂 Projects List**  

### **1️⃣ Tic-Tac-Toe Game 🎮**  
🔹 A simple Tic-Tac-Toe game where two players can play against each other.  
🔹 Features:  
✅ Click-based gameplay  
✅ Win detection & game restart
